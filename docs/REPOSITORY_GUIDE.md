# Reviewer guide

1. Start with the root [README](../README.md).
2. Read [EXPERIMENTAL_METHODOLOGY.md](EXPERIMENTAL_METHODOLOGY.md).
3. Inspect [final_metrics.csv](../results/tables/final_metrics.csv).
4. Verify epoch-level values in `results/logs/`.
5. Match scripts in `src/` with launch files in `slurm/`.
6. Review collages in `results/figures/` and samples in `results/samples/`.

The original workspace remains unchanged. Only the repository copy has normalized log names.
